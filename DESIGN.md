# SAMANVAY AI — UI/UX DESIGN DIRECTION

## DESIGN PHILOSOPHY

Build SAMANVAY AI as a **minimal, professional, clean, and highly functional government enterprise application**.

The interface should feel thoughtfully designed by a professional product design team, not like a generic AI-generated dashboard.

Prioritize:
- Simplicity and visual clarity
- Professional typography
- White backgrounds and subtle borders
- Consistent spacing and alignment
- High information density without clutter
- Excellent data tables and workflow interfaces
- Minimal but purposeful interactions

**Design inspiration:** Linear, Notion, Vercel Dashboard, and modern government administration portals.

Use these products as quality references, not templates to copy.

## COLOR SYSTEM

Keep the application predominantly white.

- **Primary Background:** `#FFFFFF`
- **Sidebar Background:** `#FAFAFA`
- **Secondary Surface:** `#F8FAFC`
- **Primary Text:** `#171717`
- **Secondary Text:** `#64748B`
- **Borders:** `#E5E7EB`
- **Primary Accent:** `#2563EB`
- **Accent Hover:** `#1D4ED8`
- **Success:** `#15803D`
- **Warning:** `#D97706`
- **Error:** `#DC2626`

Avoid colorful gradient backgrounds, neon effects, and excessive shadows.

Use blue selectively for active navigation, important actions, and links.

## TYPOGRAPHY

**Primary Font: Inter**

Use consistent typography:

- Page headings: 24–28px, semibold
- Section headings: 16–18px, semibold
- Card headings: 14px, medium
- Body text: 13–14px, regular
- Table text: 13px
- Secondary labels: 12px

Use a line height of approximately 1.4–1.5.

Prefer sentence case instead of ALL CAPS for most UI headings.

Avoid oversized typography, decorative fonts, excessive letter spacing, and unnecessary bold text.

## LAYOUT

### Sidebar
- White or very light-gray background
- Width approximately 240px
- Simple navigation icons from Lucide
- Active item with subtle blue background
- Clear grouping of navigation sections
- Thin right border
- Collapsible navigation

### Top Navigation
- White background
- Thin bottom border
- Breadcrumb navigation
- Search field
- Notification icon
- User profile dropdown
- Small "Demo Environment" indicator

### Main Content
- Comfortable horizontal padding
- Clear section headings
- Consistent grid alignment
- White cards with subtle gray borders
- Border radius of 8–10px
- Minimal or no box shadows

Avoid excessive whitespace that makes the dashboard feel empty.

## DASHBOARD DESIGN

Build a clean operational dashboard.

### Header
**Complaint Monitoring Overview**

Subtitle:
"Track institutional complaints, bureau coordination, and regulatory actions."

### KPI Cards
Use six compact cards:
- Total Complaints
- Pending Cases
- Under Process
- Disposed Cases
- Potential Overlaps
- SLA Breaches

Each card contains:
- Small muted label
- Clear numerical value
- Optional small icon
- Subtle trend indicator

Avoid large colorful card backgrounds and excessive animations.

### Analytics
Use understated Recharts visualizations with:
- Thin gridlines
- Minimal legends
- Blue as the primary data color
- Muted secondary colors
- Clear axis labels
- Simple tooltips

### Tables
Prioritize beautiful, functional data tables.

Include:
- Search and filtering
- Clear status badges
- Compact rows
- Hover highlighting
- Sortable columns
- Pagination
- Contextual actions

Tables should look like those in professional case management software, not generic dashboard templates.

## AI OVERLAP INTELLIGENCE

This must remain the most distinctive screen, but its design should be restrained.

Use a clean split-view layout:

**Left:** Potential overlap cases.

**Right:** Side-by-side complaint comparison and explainable matching evidence.

Show:
- AICTE Permanent ID match
- Semantic similarity evidence
- Shared complaint category
- Bureau involvement
- Overlap classification
- Officer review status

Use a small amber alert banner for potential conflicts.

Use a clear primary button:

**Review & Coordinate**

Include secondary actions:
- Confirm Match
- Mark Unrelated
- View Case History

Do not use robot illustrations, glowing AI graphics, artificial intelligence backgrounds, or animated neural networks.

Communicate intelligence through the quality of information, not decoration.

## MICRO-INTERACTIONS

Use only purposeful animation:
- 150–200ms hover transitions
- Subtle sidebar interactions
- Smooth modal appearance
- Simple loading indicators
- Toast feedback after actions

Avoid animated gradients, bouncing icons, excessive page transitions, and unnecessary visual effects.

## ICONS

Use **Lucide React** exclusively for interface icons.

- Default size: 16–20px
- Consistent stroke width
- Muted gray by default
- Blue for selected and important actions

No emojis in the UI.

## RESPONSIVENESS

Prioritize desktop at 1440px.

The application must remain usable on tablets and mobile devices, with responsive tables and navigation.

## PRODUCT AUTHENTICITY

Make the application feel like a genuine AICTE administrative tool.

Use realistic, clearly fictional sample records, sensible officer workflows, consistent statuses and accurate institutional terminology.

Avoid:
- Fake performance metrics
- Decorative buttons with no functionality
- Repeated generic AI marketing language
- Overly colorful dashboards
- Excessive rounded corners
- Unnecessary floating widgets
- Generic stock photography
- Fake security certifications
- Random animations

Every visible component should serve a functional purpose.

## FINAL REQUIREMENT

**The application should look like a real, production-quality government complaint management system that has been carefully designed and refined over multiple iterations.**

Aim for a visual balance of:

**70% professional administrative workspace + 20% modern analytics + 10% AI-powered decision support.**

The final interface should be minimal, elegant, fast, readable, trustworthy, and visually consistent.

Preserve all functional requirements from the original SAMANVAY AI master prompt, including the mock data, overlap detection demonstration, human review, coordination workflows, SLA monitoring and audit trail.
